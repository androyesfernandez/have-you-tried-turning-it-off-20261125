This program writes a single funny tech-support line to `/output/entry.txt` — the kind of hopeless reassurance a support agent gives a desperate customer: the ticket is logged as a priority, it will be looked at in three to five business days, but emotionally, it's already fixed.

## Run

```sh
node main.ts
```

Requires Node 22. No dependencies, no network access.
